# Contributing

Proto is a closed-source product; this repository holds its public documentation, agent skills,
configuration schema and examples. Code changes are not accepted here.

- **Bugs and feature requests:** open an [issue](https://github.com/proto-hq/proto/issues/new/choose).
- **Questions and ideas:** use [Discussions](https://github.com/proto-hq/proto/discussions).
- **Security issues:** report privately through
  [security advisories](https://github.com/proto-hq/proto/security/advisories/new).
- **Docs fixes:** open an issue describing the correction; the docs are generated from the product
  repository and synced here.
